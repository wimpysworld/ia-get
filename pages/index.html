One URL, every file

Command-line downloader
for archive.org.

ia-get downloads the files listed in an item's metadata, preserves folders, and resumes interrupted transfers.

Install ia-get See how it works

For Linux, macOS and Windows.

Files, without the clicking

Download the listed files.

Give ia-get an item /details/ URL for the full file set, or a /download/ URL for a single file. ia-get parallelises small transfers automatically and keeps a polite ceiling for archive.org.

Preview and filter
List filenames and sizes with --list before you download. Match or exclude paths with repeatable -f glob patterns.
Keep the folders
Save files into a chosen directory with -o and preserve the archive's folder structure, metadata, and torrents.
Resume and verify transfers
Stage downloads in .part files to resume interrupted transfers. ia-get checks MD5 hashes before it renames each finished file.
Check local copies
Verify an existing directory against archive metadata in read-only --check mode. Nothing downloads or changes on disk.

Usage

Choose an item. Preview. Download.

Save files in the current directory, or pick a target folder with -o.

Preview the file list

ia-get --list https://archive.org/details/deftributetozzap64

Download matching files into a folder

ia-get -o ./zzap64 -f '*djvu.*' https://archive.org/details/deftributetozzap64

Verify local files

ia-get --check -o ./zzap64 -f '*djvu.*' https://archive.org/details/deftributetozzap64
Does the item need a login?

Use a Netscape cookies.txt file exported from your browser to reuse your existing archive.org session.

ia-get --cookies cookies.txt https://archive.org/details/<identifier>

Replace <identifier> with the item's identifier. Keep your cookie file private.

How does ia-get handle parallel downloads?

ia-get parallelises downloads automatically with no extra flags. It runs up to 4 small files (under 8 MiB) or 2 medium files (8 MiB to under 64 MiB) at once. Files 64 MiB and larger, or with unknown size, transfer one at a time.

On HTTP 429 or 503 responses, ia-get honours Retry-After and steps concurrency down until transfers finish cleanly. This ceiling complies with Internet Archive's automated access guidelines. Read Parallel downloads on the wiki for full details, or use the item's .torrent file for multi-terabyte archives of multi-gigabyte files.

Read the usage guide on the wiki for filters, cookies, proxies, parallel downloads, and rate limits.

Why ia-get?

It started with ZZap!64.

High-quality magazine scans were on the Internet Archive, but torrents did not always include every available file. ia-get began as a way to download the listed files without collecting them one at a time.

The first version was a late-2023 experiment in learning Rust with AI assistance. Hear the story on Linux Matters, episode 16, or read the development history.
